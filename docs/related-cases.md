# Otros casos

Se muestran tres casos, excluyendo el actual y sin duplicados. La selección es estable por caso y día (UTC), y su orden final se mezcla.

1. Se elige un caso con la etiqueta `tiendanube`.
2. Se elige un caso con la etiqueta `independent`: Amazon, GiraFlor o Ristretto.
3. Se completa con los candidatos restantes.

En los dos primeros grupos, los destacados tienen peso 4 y los estándar 2. Para completar, el peso base es 3 para destacados y 2 para estándar; Tiendanube suma 1 y un estándar suma 2 si todavía no hay otro estándar seleccionado.

GiraFlor es destacado. La prioridad aumenta la probabilidad de aparecer, no fija una posición ni garantiza su aparición. El orden de la home es independiente: NubeCommerce, Amazon, GiraFlor, Ristretto, CTA para migrar tiendas y Recursos descargables.
